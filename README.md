# Tratamento de Dados de Transparência Pública - Itapoá/SC

Projeto de Higienização, Tratamento e Estruturação de Dados Públicos do Município de Itapoá.

## Objetivo
Processar a base de dados bruta de despesas públicas municipais para corrigir problemas de formatação e estruturação, permitindo análises precisas de movimentações financeiras.

## Tecnologias e Ferramentas
- **Linguagens/Ferramentas:** Python / Pandas / SQL
- **Editor:** VS Code
- **Formato dos Dados:** CSV

## Etapas do Tratamento de Dados
1. **Conversão de Tipos:** Acomodação e conversão de valores monetários armazenados originalmente como texto para tipos numéricos (`FLOAT` / `DECIMAL`).
2. **Padronização:** Ajuste de separadores decimais e de milhares.
3. **Organização:** Agrupamento e estruturação de despesas por órgãos, secretarias e fornecedores.

## Resultados Alcançados
- Base final tratada com mais de **R$ 127,4 Bilhões** em movimentações consolidadas de forma limpa e confiável.
- Dados prontos para integração em ferramentas de BI e análise de dados.
